# Eclipse App

Eclipse App — учебное Flutter-приложение для просмотра каталога фильмов с авторизацией, поиском, избранным и профилем пользователя. Приложение использует Supabase для аутентификации, хранения данных, Realtime-обновлений и загрузки пользовательских аватаров.

Проект демонстрирует базовую архитектуру мобильного приложения на Flutter: разделение экранов, навигацию, работу с внешним backend-сервисом, локальное хранение состояния входа и подключение мультимедийных компонентов.

## Возможности

- Регистрация, вход, выход и восстановление пароля через Supabase Auth.
- Проверка локального состояния авторизации через `shared_preferences`.
- Главный экран с подборкой фильмов и Realtime-загрузкой данных из Supabase.
- Фильтрация фильмов по жанрам и поиск по названию.
- Экран фильма с описанием, рейтингом и видеоплеером.
- Добавление и удаление фильмов из избранного для текущего пользователя.
- Профиль пользователя с редактированием имени и загрузкой аватара в Supabase Storage.
- Нижняя навигация между главной страницей, поиском, избранным и профилем.

## Архитектура проекта

Приложение построено как Flutter-клиент, который напрямую взаимодействует с Supabase. Supabase выступает внешним backend-сервисом для авторизации, таблиц, Realtime-потоков и Storage через пакет `supabase_flutter`.

Основная точка входа находится в `lib/main.dart`: там инициализируется Supabase, настраивается тема и объявляются маршруты приложения. Экраны основного интерфейса сгруппированы в `lib/bottom/`, а работа с Supabase вынесена в простые сервисные классы в `lib/database/`. Значения Supabase URL и anon key подключаются через compile-time параметры Dart.

## Запуск проекта локально

### Требования

- Flutter SDK с Dart `^3.10.8`.
- Android Studio, Xcode или другой настроенный target для запуска Flutter-приложения.
- Активный Supabase-проект с Auth, таблицами приложения и Storage bucket.

Проверить окружение Flutter:

```bash
flutter doctor
```

### Клонирование и установка зависимостей

```bash
git clone https://github.com/elon1te9/eclipse-app.git
cd eclipse-app
flutter pub get
flutter analyze
```

### Настройка Supabase

В Supabase-проекте должны быть подготовлены сущности, которые использует приложение:

- Auth для регистрации, входа, выхода и восстановления пароля.
- Таблица `users` для пользовательского профиля.
- Таблица `movie` для каталога фильмов.
- Таблица `genre` для жанров.
- Таблица `favourites` для связи пользователя с избранными фильмами.
- Storage bucket `eclipseApp` для пользовательских аватаров.

Названия таблиц и bucket должны соответствовать тем, которые используются в коде приложения.

Локальные значения Supabase передаются в приложение через `--dart-define`:

```bash
flutter run \
  --dart-define=SUPABASE_URL=<your_supabase_url> \
  --dart-define=SUPABASE_ANON_KEY=<your_supabase_anon_key>
```

Для выбора конкретного устройства:

```bash
flutter devices
flutter run -d <device-id> \
  --dart-define=SUPABASE_URL=<your_supabase_url> \
  --dart-define=SUPABASE_ANON_KEY=<your_supabase_anon_key>
```

## Конфигурация

Конфигурация Supabase описана в `lib/config/supabase_config.dart` и ожидает два compile-time значения:

```dart
SUPABASE_URL=<your_supabase_url>
SUPABASE_ANON_KEY=<your_supabase_anon_key>
```

В репозитории также есть пример локального файла `config/supabase.example.json`. Локальные значения Supabase лучше передавать через `--dart-define` или хранить в локальных конфигурационных файлах, которые не добавляются в репозиторий.

Пример безопасного формата локальных значений:

```json
{
  "SUPABASE_URL": "<your_supabase_url>",
  "SUPABASE_ANON_KEY": "<your_supabase_anon_key>"
}
```
