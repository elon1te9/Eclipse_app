# Eclipse App

Eclipse App — завершённое учебное Flutter-приложение с каталогом фильмов,
авторизацией, поиском, избранным и экраном профиля.

Проект сделан как практика мобильной разработки на Flutter. Он показывает
работу с навигацией, пользовательским интерфейсом, состоянием экранов и
интеграцией Supabase.

## Статус проекта

Проект завершён в рамках обучения. Приложение не заявляется как
production-ready: в репозитории нет отдельной серверной части, CI/CD,
описанной схемы базы данных и полноценного набора автотестов.

Для полноценной работы приложению нужен доступ к Supabase-проекту с
используемыми таблицами, Auth и storage bucket. В учебной версии конфигурация
Supabase задаётся в коде приложения, но в дальнейшем её лучше вынести в
переменные окружения или отдельный конфигурационный файл.

## Основной функционал

- Загрузочный экран при старте приложения.
- Проверка локального состояния авторизации через `shared_preferences`.
- Регистрация и вход пользователя через Supabase Auth.
- Восстановление пароля по email.
- Главный экран с подборкой фильмов.
- Просмотр списка фильмов и фильтрация по жанрам.
- Поиск фильмов по названию.
- Экран детальной информации о фильме с видеоплеером и пользовательской
  оценкой на UI.
- Добавление и удаление фильмов из избранного.
- Профиль пользователя с редактированием имени и загрузкой аватара через
  галерею.
- Выход из аккаунта.

## Архитектура / структура приложения

Приложение построено на стандартной структуре Flutter-проекта. Основная логика
разделена по экранам и простым сервисным классам:

- `main.dart` инициализирует Supabase, настраивает тему и маршруты приложения.
- `loading.dart` показывает стартовый экран загрузки.
- `check.dart` проверяет, авторизован ли пользователь локально.
- `auth.dart`, `reg.dart`, `recovery_password.dart` отвечают за вход,
  регистрацию и восстановление пароля.
- `home.dart` содержит основной контейнер с нижней навигацией.
- Файлы в `lib/bottom/` реализуют вкладки главного экрана.
- Файлы в `lib/database/` инкапсулируют работу с Supabase Auth, таблицами
  пользователей, избранным и storage.

## Установка и запуск

1. Установить Flutter SDK и проверить окружение:

```bash
flutter doctor
```

2. Клонировать репозиторий:

```bash
git clone https://github.com/elon1te9/eclipse-app.git
cd eclipse-app
```

3. Установить зависимости:

```bash
flutter pub get
```

4. Настроить Supabase-проект для работы приложения.

5. Запустить приложение на подключённом устройстве или эмуляторе:

```bash
flutter run
```

6. При необходимости выбрать конкретную платформу:

```bash
flutter devices
flutter run -d <device-id>
```

## Настройка Supabase

Для запуска проекта нужен собственный Supabase-проект с настроенными
компонентами, которые используются в приложении:

- Supabase Auth для регистрации, входа, выхода и восстановления пароля.
- Таблицы для пользователей, фильмов, жанров и избранного.
- Storage bucket для загрузки и получения аватаров пользователей.
- Правила доступа к таблицам и Storage bucket, соответствующие логике
  приложения.

Схема Supabase не хранится в репозитории, поэтому перед запуском её нужно
подготовить отдельно. В учебной версии URL проекта и anon key задаются в коде,
но для дальнейшего развития проекта их лучше вынести из `main.dart` в
переменные окружения или конфигурационный файл.

## Ограничения текущей версии

- В репозитории нет описания схемы Supabase и миграций базы данных.
- Конфигурация Supabase в учебной версии находится в коде приложения.
- Текущий тестовый файл остался от стандартного Flutter-шаблона и не покрывает
  актуальную логику приложения.
- Обработка ошибок и загрузочных состояний реализована не на всех экранах
  одинаково.
- Проект ориентирован на демонстрацию учебной практики, а не на публикацию
  готового продукта.
